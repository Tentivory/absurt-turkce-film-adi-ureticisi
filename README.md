# Absürt Türkçe Film Adı Üreticisi

## Dünyanın En Ciddi, En Bilimsel ve En Gereksiz Yazılımı

Bu proje, evrenin en derin sorunlarından birini çözmek için tasarlanmıştır: **Türkçe film adlarının yetersizliği.**

Her gün binlerce insan "Ne film izlesem?" diye sorarken, biz bu soruyu kökünden çözdük. Artık absürt, anlamsız ve tamamen uydurma film adları üretebilirsiniz. Bilimsel olarak kanıtlanmıştır ki (kanıtlanmamıştır), bu adlar Oscar'a aday olmaya (olmamaya) müsaittir.

### Nasıl Çalışır?

1. Programı çalıştırın.
2. Biraz bekleyin (dram için).
3. Absürt bir film adı alın.
4. Şaşırın.
5. Tekrar çalıştırın.

### Kurulum ve Kullanım

```bash
python film_adi_uretici.py
```

Gizli siyasi mesajı görmek için (saklıdır, bulursan tebrikler):

```bash
python film_adi_uretici.py --gizli
```

**Uyarı:** Gizli mesaj siyasi anlam içerir. Ciddiye almayın. (Alın.)

### Özellikler

- %100 Türkçe
- %100 Absürt
- %0 Anlam
- Gerçekten çalışır
- Gizli siyasi mesaj içerir (saklı)
- Kayyum onaylı (sözde)
